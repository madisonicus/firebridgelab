# Examples gallery

Six fictional households ship with FIRE Bridge Lab as plan files. Each one is a
starting point: copy it with `firebridgelab init --example <name> my-plan.toml`,
edit the numbers, and run it. In the web UI, pick one from the **Examples** menu.

Below each story is the whole plan file and what `firebridgelab run` prints for it
(the year-by-year table is left out). The numbers depend on the return data and move
slightly when the Shiller file is revised; this page is generated by
`scripts/build_examples_page.py`. [What the numbers mean](faq.md#what-do-the-numbers-mean).

*All households are fictional. Educational software, not financial advice.*

## Deferred federal couple

`deferred-federal-couple`: Both left federal service at 50; pensions frozen until 62, then FERS COLA.

Dana and Robin both left federal service at 50 with enough years for a
deferred annuity but before their minimum retirement age. A deferred FERS
annuity is frozen in nominal dollars from separation until it starts at 62,
then receives the FERS "diet" COLA. The TSP, a traditional IRA, a taxable
account and a small Roth carry the twelve bridge years.

Try:

```bash
firebridgelab sweep deferred-federal-couple.toml --set income_streams.dana_ss.start_age=62,67,70
```

??? note "The plan file"

    ```toml
    # Deferred federal couple (fictional).
    #
    # Dana and Robin both left federal service at 50 with enough years for a
    # deferred annuity but before their minimum retirement age. A deferred FERS
    # annuity is frozen in nominal dollars from separation until it starts at 62,
    # then receives the FERS "diet" COLA. The TSP, a traditional IRA, a taxable
    # account and a small Roth carry the twelve bridge years.
    #
    # Try: firebridgelab sweep deferred-federal-couple.toml \
    #        --set income_streams.dana_ss.start_age=62,67,70

    name = "Deferred federal couple"
    description = "Both left federal service at 50; pensions frozen until 62, then FERS COLA."

    [[people]]
    name = "Dana"
    start_age = 50
    end_age = 95

    [[people]]
    name = "Robin"
    start_age = 50
    end_age = 95

    # The annuity amounts are the nominal checks at 62 (nominal_until_start), so
    # inflation erodes them for twelve years before the first payment.
    [[income_streams]]
    id = "dana_fers"
    kind = "pension"
    owner = "a"
    amount = 31_000
    start_age = 62
    nominal_until_start = true
    cola = "fers_diet"
    survivor_fraction = 0.5     # full survivor annuity elected

    [[income_streams]]
    id = "robin_fers"
    kind = "pension"
    owner = "b"
    amount = 22_000
    start_age = 62
    nominal_until_start = true
    cola = "fers_diet"
    survivor_fraction = 0.5

    [[income_streams]]
    id = "dana_ss"
    kind = "social_security"
    owner = "a"
    amount = 27_000    # at full retirement age
    start_age = 67     # claim age

    [[income_streams]]
    id = "robin_ss"
    kind = "social_security"
    owner = "b"
    amount = 21_000
    start_age = 67

    # FEHB premiums continue in retirement; modeled as required spending.
    [[spending_adjustments]]
    id = "fehb"
    owner = "household"
    amount = 7_000
    start_age = 50
    end_age = 96

    [portfolio]
    taxable = 350_000
    tax_deferred = 950_000     # TSP and traditional IRA
    roth = 150_000
    annual_fee = 0.0005

    [allocation]
    weights = { us_total_market = 0.60, us_agg_bonds = 0.40 }

    [spending]
    annual = 78_000
    rule = "guardrails"
    floor = 62_000
    ceiling = 110_000

    [survivor]
    decedent = "a"
    age = 84

    [simulation]
    trials = 10_000
    stress = ["stagflation_1970s", "historical_depression_1929"]
    ```

## Leanfire single

`leanfire-single`: Retired at 40 on $45k a year, no pension, Social Security at 70.

Casey, 40, has saved $1.15M and spends $45,000 a year. No pension: the
portfolio carries everything until Social Security, claimed at 70 for the
largest benefit. Guardrails trim spending in bad markets but never below
$38,000.

Try:

```bash
firebridgelab sweep leanfire-single.toml --set spending.annual=40000:55000:5000
```

??? note "The plan file"

    ```toml
    # Leanfire single (fictional).
    #
    # Casey, 40, has saved $1.15M and spends $45,000 a year. No pension: the
    # portfolio carries everything until Social Security, claimed at 70 for the
    # largest benefit. Guardrails trim spending in bad markets but never below
    # $38,000.
    #
    # Try: firebridgelab sweep leanfire-single.toml --set spending.annual=40000:55000:5000

    name = "Leanfire single"
    description = "Retired at 40 on $45k a year, no pension, Social Security at 70."

    [[people]]
    name = "Casey"
    start_age = 40
    end_age = 95

    [[income_streams]]
    id = "ss"
    kind = "social_security"
    amount = 19_000            # at full retirement age (reduced by the zero years)
    start_age = 70

    # Marketplace health insurance until Medicare.
    [[spending_adjustments]]
    id = "aca"
    amount = 5_000
    start_age = 40
    end_age = 65

    [portfolio]
    balance = 1_150_000
    annual_fee = 0.0005

    [allocation]
    weights = { us_total_market = 0.75, us_agg_bonds = 0.25 }

    [spending]
    annual = 45_000
    rule = "guardrails"
    floor = 38_000
    ceiling = 60_000

    [simulation]
    trials = 10_000
    distribution = "student_t"   # fatter-tailed Monte Carlo
    ```

## MRA+10 single retiree

`mra10-single`: Federal retiree at MRA with a 25% reduced annuity, no COLA until 62.

Morgan retires at 57, the minimum retirement age, with 15 years of service.
An MRA+10 annuity taken before 62 is reduced 5% for each year under 62:
25% here, so a $30,000 annuity pays $22,500. FERS retirees under 62 get no
COLA, so the annuity is modeled as two streams: a fixed nominal check from
57 to 62, then the same nominal check (deflated to today's dollars) with the
FERS COLA from 62 on.

Try:

```bash
firebridgelab solve mra10-single.toml --confidence 0.9
```

??? note "The plan file"

    ```toml
    # MRA+10 single federal retiree (fictional).
    #
    # Morgan retires at 57, the minimum retirement age, with 15 years of service.
    # An MRA+10 annuity taken before 62 is reduced 5% for each year under 62:
    # 25% here, so a $30,000 annuity pays $22,500. FERS retirees under 62 get no
    # COLA, so the annuity is modeled as two streams: a fixed nominal check from
    # 57 to 62, then the same nominal check (deflated to today's dollars) with the
    # FERS COLA from 62 on.
    #
    # Try: firebridgelab solve mra10-single.toml --confidence 0.9

    name = "MRA+10 single retiree"
    description = "Federal retiree at MRA with a 25% reduced annuity, no COLA until 62."

    [[people]]
    name = "Morgan"
    start_age = 57
    end_age = 95

    [[income_streams]]
    id = "fers_before_62"
    kind = "pension"
    amount = 22_500
    start_age = 57
    end_age = 62
    cola = "none"              # fixed nominal: loses inflation each year

    [[income_streams]]
    id = "fers_from_62"
    kind = "pension"
    amount = 22_500            # the same nominal check, worth less by 62
    start_age = 62
    nominal_until_start = true
    cola = "fers_diet"

    [[income_streams]]
    id = "ss"
    kind = "social_security"
    amount = 24_000
    start_age = 67

    [[spending_adjustments]]
    id = "fehb"
    amount = 3_600
    start_age = 57
    end_age = 96

    [portfolio]
    taxable = 80_000
    tax_deferred = 520_000     # TSP
    roth = 60_000

    [allocation]
    weights = { us_total_market = 0.50, it_treasury = 0.40, st_treasury = 0.10 }

    [spending]
    annual = 44_000
    rule = "constant"
    ```

## Part-time bridge

55, which shrinks the early withdrawals. Both buy marketplace health
insurance until Medicare at 65. The portfolio is split across taxable,
tax-deferred and Roth accounts, so federal tax is modeled and the pre-59½
penalty applies if the taxable account runs dry first.

Try:

```bash
firebridgelab sweep part-time-bridge.toml --set income_streams.sam_consulting.end_age=50,53,55,58
```

## Rental and pension

fixed COLA; Lee (60) has none. A rental duplex nets $18,000 a year until it
is sold at Pat's 75, with 60% of the price a taxable gain. The survivor case
has Pat dying at 80, so Lee keeps half the pension and the larger Social
Security benefit.

```bash
firebridgelab run rental-and-pension.toml --mode stress
```

## SS-only couple, age gap

`ss-only-couple-age-gap`: No pensions, a 5-year age gap, survivor case at Jordan's 84.

Jordan is 62 and Avery is 57. No pensions: Jordan delays Social Security to
70 so the larger benefit lasts as the survivor benefit; Avery claims at 67.
The plan runs until Avery is 95 (Jordan's 100). The survivor case has Jordan
dying at 84: Avery keeps the larger benefit and spends 75%. A glidepath holds
more bonds until Jordan's benefit starts, then more stocks.

Try:

```bash
firebridgelab sweep ss-only-couple-age-gap.toml --set income_streams.jordan_ss.start_age=67,70 --set survivor.age=75,84,92
```

??? note "The plan file"

    ```toml
    # Social Security-only couple with a five-year age gap (fictional).
    #
    # Jordan is 62 and Avery is 57. No pensions: Jordan delays Social Security to
    # 70 so the larger benefit lasts as the survivor benefit; Avery claims at 67.
    # The plan runs until Avery is 95 (Jordan's 100). The survivor case has Jordan
    # dying at 84: Avery keeps the larger benefit and spends 75%. A glidepath holds
    # more bonds until Jordan's benefit starts, then more stocks.
    #
    # Try: firebridgelab sweep ss-only-couple-age-gap.toml \
    #        --set income_streams.jordan_ss.start_age=67,70 --set survivor.age=75,84,92

    name = "SS-only couple, age gap"
    description = "No pensions, a 5-year age gap, survivor case at Jordan's 84."

    [[people]]
    name = "Jordan"
    start_age = 62
    end_age = 95

    [[people]]
    name = "Avery"
    start_age = 57
    end_age = 95

    [[income_streams]]
    id = "jordan_ss"
    kind = "social_security"
    owner = "a"
    amount = 34_000
    start_age = 70

    [[income_streams]]
    id = "avery_ss"
    kind = "social_security"
    owner = "b"
    amount = 16_000
    start_age = 67

    [[spending_adjustments]]
    id = "avery_aca"
    owner = "b"
    amount = 9_000
    start_age = 57
    end_age = 65

    [portfolio]
    balance = 1_050_000

    [allocation]
    mode = "glidepath"
    # Phases start at the plan start, at 60 (penalty-free account access), and at
    # each stream's start age on Jordan's axis: here 62 (start), 70 (Jordan's SS)
    # and 72 (Avery's SS at her 67). One weights table per phase, in order.
    phases = [
      { us_total_market = 0.45, us_agg_bonds = 0.55 },
      { us_total_market = 0.55, us_agg_bonds = 0.45 },
      { us_total_market = 0.60, us_agg_bonds = 0.40 },
    ]

    [spending]
    annual = 62_000
    rule = "constant"

    [survivor]
    decedent = "a"
    age = 84
    spending_fraction = 0.75
    ```
